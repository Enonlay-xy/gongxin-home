# 多语言(i18n)功能设计文档

## 1. 需求概述

为 Vue 门户网站添加多语言国际化支持，包括以下功能：

- 支持简体中文(zh-CN)、繁体中文(zh-TW)、英文(en)三种语言
- 根据访问者 IP 地址自动判断默认语言：
  - 中国大陆(CN) → 简体中文
  - 台湾(TW)、香港(HK)、澳门(MO) → 繁体中文
  - 其余地区 → 英文
- 页面右上角提供语言切换器，支持手动切换
- 用户手动切换后，通过 localStorage 记住偏好，下次访问优先使用

## 2. 技术选型

| 技术 | 版本 | 用途 |
|------|------|------|
| vue-i18n | ^9 | Vue 3 国际化核心库 |
| ipapi.co | - | 免费 IP 地理位置 API |
| localStorage | - | 持久化用户语言偏好 |

## 3. 语言检测逻辑

```
应用启动
  │
  ▼
检查 localStorage 是否有已保存语言？
  │
  ├─ 有 → 直接使用保存的语言
  │
  └─ 无 → 调用 https://ipapi.co/json/ 获取国家/地区码
            │
            ├─ country_code === "CN" → zh-CN
            ├─ country_code === "TW"│"HK"│"MO" → zh-TW
            └─ 其他 → en
```

## 5. 语言切换器 UI

位置：Header 组件右上角

- 显示当前语言的标识文字
- 点击展开下拉菜单，包含三种语言选项
- 选中后切换语言并保存到 localStorage
- 响应式适配移动端

## 6. 实现计划

1. 安装 vue-i18n 依赖
2. 创建 i18n 目录和语言文件(zh-CN.json, zh-TW.json, en.json)
3. 实现 i18n 初始化逻辑(含 IP 检测)
4. 修改 Header.vue 添加语言切换器
5. 逐个改造组件和页面：$t() 替换硬编码中文
6. 构建验证
