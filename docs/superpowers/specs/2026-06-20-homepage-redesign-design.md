## 1. 背景与目标

### 1.1 现状

现有项目 `gongxin-home` 是 Vue 3 + Vite + Tailwind CSS + vue-i18n 的纯前端门户网站，已包含首页、关于我们、产品服务、联系我们四个区块，支持简体中文/繁体中文/英文三语切换。但当前内容为通用占位内容（云服务、信息安全、大数据），并非资质检测公司的真实业务。

### 1.2 目标

将首页改造为符合"资质检测公司"行业特征的门户首页，参考安信检测网站的模块结构与布局，采用深蓝专业风格，展示公司业务能力、资质与合作实验室，并在明显位置突出联系电话 `15207111291`。

### 1.3 范围界定

| 包含 | 不包含 |

### 2.1 多页面架构蓝图

```

│   ├── Header（导航 + 语言切换 + 醒目电话 15207111291）

│   ├── 关于我们
│   ├── 服务项目 Tab
│   ├── 服务领域
│   ├── 资质与合作实验室
│   ├── 联系 CTA
│   └── Footer
├── 关于我们详情页（后续二期）
├── 服务项目详情页（后续二期）
├── 服务领域详情页（后续二期）
├── 资质详情页（后续二期）
└── 联系我们页（后续二期）
```

### 2.2 第一期范围：仅首页

- **保留**：现有 Vue 3 + Vite + Tailwind + vue-i18n 技术栈，不引入 vue-router（二期再加）
- **首页形态**：单页滚动，各模块作为 `<section>` 区块纵向排列（沿用现有 `App.vue` 结构）
- **导航**：Header 锚点跳转到对应区块（复用现有 id：#home/#about/#products/#contact）
- **二期预留**：详情页入口在首页各模块"查看更多"按钮处，一期先做占位（按钮样式但提示"即将上线"或预留路由）

### 2.3 技术决策

| 项目 | 决策 | 理由 |
|------|------|------|
| 路由 | 一期不引入 vue-router，用锚点滚动；二期引入 | 一期单页足够，降低复杂度 |
| 状态管理 | 不需要 | 纯展示型项目 |
| 图片资源 | 放 `src/assets/images/`，按模块分子目录 | 便于 Vite 打包与引用 |
| 数据来源 | 检测项目/服务领域等列表数据写在组件 `setup` 内（静态），i18n 文案走 locale 文件 | 无后端，静态数据即可 |
| 响应式 | 移动端优先，断点 sm/md/lg/xl | 行业网站移动端流量占比高 |

### 3.2 模块 1：Header（改造现有）

- **布局**：左 Logo + 中导航 + 右语言切换 + 醒目电话按钮
- **电话展示**：右上角醒目按钮 `15207111291`，深蓝底白字 + 电话图标（`Phone` from lucide），移动端常驻显示
- **导航项**：首页 / 关于我们 / 服务项目 / 服务领域 / 资质合作 / 联系我们（锚点跳转）
- **语言切换**：保留现有下拉（简体/繁体/英文）
- **移动端**：导航折叠为汉堡菜单
- **素材**：使用 `设计素材/公司logo/115a0af6e070ff1f01405d8abe0a163b.png` 替换现有占位 Logo

### 3.3 模块 2：Banner 轮播（新建，改造 Hero）

- **形式**：全宽轮播，3-4 张图，自动播放（5 秒间隔）+ 手动切换 + 指示器圆点
- **图片**：使用 `设计素材/公司照片/` 与 `设计素材/实验室图片/` 中的真实照片
- **文案**：每张图叠加标题 + 副标题 + CTA 按钮
  - 图 1：标题"专业检测 · 权威认证 · 值得信赖" + 按钮"了解我们"
  - 图 2：标题"一站式检测认证服务" + 按钮"查看服务"
  - 图 3：标题"国际权威合作实验室" + 按钮"查看资质"
- **视觉**：深蓝渐变遮罩（从左到右 `from-primary-900/70`）+ 左对齐白色文案，保证文字可读性
- **组件实现**：自建轻量轮播（不引第三方库），用 `setInterval` + Vue `<transition>` 实现

### 3.4 模块 3：关于我们（改造现有 About 区块）

- **布局**：左文右图（公司前台照片），深蓝标题 + 正文 + "了解更多"按钮
- **内容**：公司简介（多领域综合检测、CMA/CNAS 资质、服务理念），文案标注 `[待替换]`
- **素材**：`设计素材/公司照片/公司前台.jpg`
- **i18n**：文案走 locale 文件
- **二期入口**："了解更多"按钮预留详情页跳转

### 3.5 模块 4：服务项目 Tab（新建，核心模块）

- **形式**：Tab 切换，参考安信的"认证项目/体系项目/检测项目"分类
- **Tab 分类**（建议，可调）：
  - **认证项目**：CB / CE / CCC / CQC / ETL / PSE / KC / RCM / SAA / GS 等
  - **体系项目**：ISO9001 / ISO14001 / ISO45001 等
  - **检测项目**：安规测试 / EMC 电磁兼容 / 化学检测（RoHS） / 射频测试 等
- **展示**：每个 Tab 下用网格卡片列出具体项目（图标 + 名称 + 简述），每行 3-4 个
- **交互**：Tab 切换有过渡动画，卡片悬浮上移 + 阴影
- **数据**：项目列表写在组件内静态数组，名称与描述走 i18n
- **二期入口**：卡片点击预留详情页跳转

**数据结构示例**：

```js
const serviceTabs = [
  {
    key: 'certification',
    labelKey: 'service_tab_certification',
    items: [
      { nameKey: 'cert_cb', descKey: 'cert_cb_desc', icon: markRaw(Award) },
      { nameKey: 'cert_ce', descKey: 'cert_ce_desc', icon: markRaw(BadgeCheck) },
      // ...
    ]
  },
  { key: 'system', labelKey: 'service_tab_system', items: [...] },
  { key: 'testing', labelKey: 'service_tab_testing', items: [...] }
]
```

### 3.6 模块 5：服务领域（新建）

- **形式**：网格卡片（桌面 3 列，平板 2 列，移动 1 列），每张卡 = 产品图 + 领域名称
- **领域**（建议）：家用电器 / 灯具照明 / 电子电器 / 音视频设备 / 玩具产品 / 机械设备
- **素材**：`设计素材/一些可参考的官方图片/` 中的 JPG
- **交互**：卡片悬浮放大图片 + 显示"查看详情"遮罩
- **二期入口**：点击预留详情页跳转

### 3.7 模块 6：资质与合作实验室（新建）

- **形式**：分两部分纵向排列
  - **资质证书**：CMA / CNAS 等资质徽章横排展示（图标 + 名称）
  - **合作实验室**：使用 `设计素材/实验室图片/` 中的图片，3 列网格
- **实验室图片**：TUV南德/莱茵合作实验室、CQC 合作实验室、CSA 合作实验室、化学实验室、安规实验室、电磁兼容实验室
- **布局**：资质徽章横排 + 实验室图片网格，每张图带标题说明
- **目的**：建立权威信任感

### 3.8 模块 7：联系 CTA（改造现有 Contact 区块）

- **布局**：深蓝背景（`bg-primary-900`）全宽区块，左联系信息 + 右留言表单（保留现有表单）
- **醒目电话**：大字号显示 `15207111291` + "服务热线"标签 + 电话图标
- **其他信息**：公司邮箱、地址（待提供具体值，先用 `[待提供]` 占位）
- **表单**：保留现有留言表单（姓名/电话/需求），提交暂为前端提示（`alert` 或 toast）

### 3.9 模块 8：Footer（改造现有）

## 4. 视觉设计系统

### 4.1 配色方案（深蓝专业风）

更新 `tailwind.config.js` 的 `primary` 色板：

```
primary（深蓝）:
  - primary-50:  #eff6ff  (浅底背景)
  - primary-100: #dbeafe  (浅色徽章)
  - primary-200: #bfdbfe
  - primary-500: #1e40af  (主按钮 / 标题)
  - primary-600: #1e3a8a  (悬浮态)
  - primary-700: #1e3a8a  (深色区块)
  - primary-900: #0f172a  (Footer / CTA 背景)

辅助色:
  - accent: #0ea5e9 (青蓝点缀，用于图标 / 高亮)

中性色:
  - gray-50 / gray-100 / gray-600 / gray-900 (文本 / 背景层次)

功能色:
  - success #16a34a
  - warning #f59e0b
  - danger  #dc2626
```

### 4.2 字体与排版

- **中文字体**：`"PingFang SC", "Microsoft YaHei", sans-serif`（系统字体栈，零加载成本）
- **英文字体**：`"Inter", system-ui, sans-serif`
- **标题层级**：
  - H1：`text-4xl md:text-5xl font-bold text-gray-900`
  - H2：`text-3xl md:text-4xl font-bold text-gray-900`
  - H3：`text-xl font-semibold text-gray-900`
- **正文**：`text-base text-gray-600 leading-relaxed`
- **章节标题样式**：统一"中文标题 + 英文副标题"双行样式（参考安信风格），如"关于我们 / About Us"，下方加短装饰线

### 4.3 间距与布局

- **容器宽度**：`max-w-7xl mx-auto px-4 sm:px-6 lg:px-8`（沿用现有）
- **章节间距**：`py-20`（桌面）/ `py-12`（移动）
- **卡片圆角**：`rounded-xl`（12px）
- **阴影**：默认无，悬浮 `hover:shadow-xl transition-all`

### 4.4 组件视觉规范

| 组件 | 样式规范 |
|------|----------|
| 按钮-主要 | `bg-primary-500 text-white px-6 py-3 rounded-lg hover:bg-primary-600 transition-colors` |
| 按钮-次要 | `border-2 border-primary-500 text-primary-500 hover:bg-primary-50 transition-colors` |
| 卡片 | `bg-white rounded-xl p-8 hover:shadow-xl hover:-translate-y-1 transition-all` |
| 章节标题 | 居中，中文 H2 + 英文小字副标题 + 下方短装饰线（`w-16 h-1 bg-primary-500 mx-auto`） |
| Tab 选中态 | 下划线 `border-b-2 border-primary-500` + 深蓝文字 |
| Tab 未选中 | 灰色文字 `text-gray-500` |

### 4.5 响应式断点

- **移动端**（<768px）：单列布局，Banner 高度降低，Tab 横向滚动，导航折叠为汉堡菜单
- **平板**（768-1024px）：2 列网格
- **桌面**（>1024px）：3 列网格，完整布局

## 6. i18n 与内容策略

### 6.1 多语言策略

- **保留**：现有 zh-CN / zh-TW / en 三语 + IP 检测逻辑
- **新增 key 命名**：沿用 snake_case，按模块前缀分组
  - `banner_*`（轮播文案）
  - `about_*`（关于我们）
  - `service_tab_*` / `cert_*` / `system_*` / `test_*`（服务项目）
  - `field_*`（服务领域）
  - `qual_*`（资质合作）
  - `cta_*`（联系区块）
- **电话号码**：硬编码在组件中（`15207111291`），不走 i18n

### 6.2 内容占位策略

由于一期只出设计方案，内容分两类处理：

| 内容类型 | 处理方式 |
|----------|----------|
| 公司简介、服务理念 | 参考安信文案风格写**行业通用占位文案**，标注 `[待替换]` |
| 认证项目列表（CB/CE/CCC 等） | 使用**行业通用清单**，公信实际项目待确认 |
| 服务领域 | 使用**行业通用分类**（家电/灯具/电子电器等） |
| 联系信息 | 电话用真实值 `15207111291`，邮箱/地址用占位 `[待提供]` |
| 资质证书 | CMA/CNAS 通用展示，具体证书编号待提供 |

## 7. 关键约束与决策记录
